# Система автоматизации документооборота ООО «Битлджем»

Десктопное приложение на C# / WPF / Entity Framework Core / MS SQL Server.
Разработано в соответствии с дипломным проектом.

## Что реализовано (6 модулей из диплома)

1. **Окно авторизации** — вход по логину и паролю, пароли хранятся в виде хеша (BCrypt).
2. **Технологические карты** — создание, редактирование, согласование, утверждение, возврат на доработку, состав (компоненты).
3. **Лабораторные испытания** — регистрация результатов по партиям продукции.
4. **Заключения о соответствии** — оформление заключений по протоколам.
5. **Отчёты** — отчёты по картам и испытаниям с экспортом в Excel (ClosedXML).
6. **Журнал действий пользователей** — автоматическая фиксация всех действий.

Дополнительно: модуль партий продукции (для оператора).

## Разграничение прав по ролям (RBAC)

| Роль | Доступные разделы |
|------|-------------------|
| Технолог | Технологические карты (создание, редактирование, отправка на согласование) |
| Генеральный директор | Согласование карт (утверждение / возврат) |
| Оператор производства | Утверждённые карты, партии продукции |
| Лаборант | Лабораторные испытания |
| Специалист по качеству | Заключения о соответствии |

Отчёты и журнал действий доступны всем ролям.

## Требования

- Windows 10/11
- .NET 8 SDK (или новее) — https://dotnet.microsoft.com/download
- Visual Studio 2022 (с компонентом «.NET desktop development»)
- MS SQL Server LocalDB (ставится вместе с Visual Studio) или MS SQL Server Express

## Как запустить

### Вариант 1 — через Visual Studio (рекомендуется)

1. Открыть файл `BitldzhemDocFlow.csproj` в Visual Studio 2022.
2. Дождаться, пока восстановятся NuGet-пакеты (EF Core, BCrypt, ClosedXML).
3. Нажать F5 (запуск).

При первом запуске база данных `BitldzhemDocFlow` создаётся автоматически,
справочники и тестовые пользователи заполняются сами.

### Вариант 2 — через командную строку

```
cd BitldzhemDocFlow
dotnet restore
dotnet run
```

## Если база данных не подключается

По умолчанию используется LocalDB:
```
Data Source=(localdb)\MSSQLLocalDB;Initial Catalog=BitldzhemDocFlow;...
```

Если у вас обычный MS SQL Server, откройте файл `Data/AppDbContext.cs`
и измените `ConnectionString` — замените `Data Source` на имя вашего сервера, например:
```
Data Source=DESKTOP-XXXX\SQLEXPRESS;Initial Catalog=BitldzhemDocFlow;Integrated Security=True;TrustServerCertificate=True
```

## Сквозной сценарий для демонстрации на защите

1. Войти как **tehnolog** → создать технологическую карту, добавить состав → «На согласование».
2. Войти как **director** → открыть раздел «Согласование карт» → «Утвердить» (или «Вернуть на доработку» с комментарием).
3. Войти как **operator** → «Партии продукции» → создать партию по утверждённой карте.
4. Войти как **laborant** → «Лабораторные испытания» → зарегистрировать результат по партии.
5. Войти как **quality** → «Заключения о соответствии» → оформить заключение по протоколу.
6. В разделе «Отчёты» → сформировать отчёт и экспортировать в Excel.
7. В разделе «Журнал действий» → посмотреть, что все действия зафиксированы.

## Оформление (визуальная тема)

Приложение оформлено в премиальной цветовой гамме «парфюмерный люкс»:
- **Графит** (#1A1A1A) — боковое меню, заголовки таблиц
- **Золото** (#C0A062) — кнопки, акценты, активные пункты меню
- **Слоновая кость** (#F7F5F0) — фон рабочей области

Все стили вынесены в файл `Theme.xaml` и подключаются глобально через `App.xaml`.
Чтобы сменить цвет, достаточно изменить значения в начале `Theme.xaml`
(например, `GoldColor` на другой акцентный цвет).

Боковое меню использует иконки шрифта Segoe MDL2 Assets (входит в Windows 10/11).
